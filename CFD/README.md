# Eurofighter External-Flow Demo

This folder contains a reproducible, exploratory steady-RANS case generated by `run_eurofighter_demo.py`, plus a saved OpenFOAM streamline sample. It is a visualization exercise, not validated aerodynamic or flight-performance data.

## Assumptions and limitations

- Inlet speed: 30 m/s; angle of attack: 0 degrees. These are demonstration inputs, not an operating envelope.
- The current runner seeds 31 points across the span at z=1.0 m and another 31 at z=0.5 m, both upstream of the aircraft.
- Solver and model: OpenFOAM `simpleFoam`, incompressible steady RANS, k-omega SST.
- Air properties: density 1.225 kg/m3 and kinematic viscosity 1.5e-5 m2/s.
- STL scale is assumed to be 0.1 m per source unit.
- The saved 200-iteration run produced 62 streamlines: 31 seeded at z=1.0 m (9,726 samples) and 31 at z=0.5 m (10,489 samples). Its mesh had 54,815 cells; `checkMesh` reported 3,006 concave cells and failed one mesh check.
- The mesh quality issue, simplified setup, limited iteration count, and unvalidated geometry/model mean these results must not be used for design decisions or aircraft performance claims.

## Run

Initialize the installed OpenFOAM v2606 environment first (on Windows, use its `setEnvVariables-v2606.bat`). Python must have PyFoam installed, and the local source STL must be available; the source STL is intentionally excluded from the repository.

```powershell
python CFD/run_eurofighter_demo.py --stl assets/eurofighter-typhoon.stl --speed 30 --angle 0 --iterations 200
```

The runner creates a unique case under `%TEMP%\openfoam-eurofighter\run-*`, unless `--case PATH` is supplied. Streamlines are written under:

```text
<case>/postProcessing/sets/airflowStreamlinesUpper/<time>/track0.vtp
<case>/postProcessing/sets/airflowStreamlinesLower/<time>/track0.vtp
```

The script prints both `airflowStreamlinesUpper` and `airflowStreamlinesLower` output directories when the run finishes. OpenFOAM and PyFoam version behavior can vary; this runner includes Windows compatibility workarounds for the tested environment.

## Render a saved result

The renderer requires Python packages `numpy` and `matplotlib`. It reads the aircraft geometry from the indexed mesh bundle generated by `build_mesh_bundle.py` (`assets/eurofighter-mesh-data.js` by default), so rendering saved VTP files does not require the source STL.

```powershell
python CFD/render_streamlines.py --vtk CFD/results/eurofighter-streamlines-upper-t200.vtp CFD/results/eurofighter-streamlines-lower-t200.vtp --output CFD/results/eurofighter-streamlines-t200.png --data-js CFD/results/eurofighter-streamlines-t200-data.js
```

The checked-in upper and lower VTP files, PNG, and interactive data bundle are from the same 200-iteration OpenFOAM run. The PNG shows the aircraft surface reconstructed from the indexed mesh bundle and streamlines in three dimensions, with line color indicating velocity magnitude. It is not a validated surface or wake visualization.

## Interactive viewer

Open `viewer.html` in a modern browser through Live Preview or another local HTTP server to load the full-resolution `assets/eurofighter-typhoon.stl` (1,186,840 faces). If the full STL is unavailable, such as on GitHub Pages where the large source file is ignored, the viewer falls back to the embedded 60,000-face mesh. Three.js is loaded from jsDelivr and requires an internet connection. Drag to orbit, use the wheel to zoom, and use the controls to pause the moving particles, change their speed, or reset the camera. The viewer draws 16 representative tubes from the 62 calculated streamlines; one particle per displayed tube advances at the same normalized phase. Tube color uses a shared p10-p90 scale from the sampled OpenFOAM velocity magnitudes; values outside that range are clamped, and both thresholds are shown in m/s. Tube opacity fades smoothly to zero at both endpoints. The aircraft mesh remains fixed in the hero-style orientation; its resolution is shown in the viewer.

To rebuild the bundled trajectory data after running a new simulation:

```powershell
python CFD/render_streamlines.py --vtk PATH\TO\airflowStreamlinesUpper\track0.vtp PATH\TO\airflowStreamlinesLower\track0.vtp --output CFD/results/eurofighter-streamlines-t200.png --data-js CFD/results/eurofighter-streamlines-t200-data.js
```
